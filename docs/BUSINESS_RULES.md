3. BUSINESS_RULES.md

This is one of the most important documents.

For example:

Admission
Application

↓

Approved

↓

Payment

↓

Registration Number Generated

↓

Student Account Created

Rules like:

Registration number cannot exist before payment.
Student account is created only after registration.
Default password is "password".
Student must change password at first login.
Admin can reset passwords.

These rules are independent of the code and define how the system should behave.
